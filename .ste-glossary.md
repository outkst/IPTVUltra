# Project glossary: IPTV Ultra (ASD-STE100)

This glossary gives the technical nouns (tn) and the technical verbs (tv) of
IPTV Ultra. The STE checker (`ste_check.py`) reads this file and the
glossary of the user for all projects (`~/.claude/ste/glossary.md`). Each
word has 1 meaning. For the notes "Conflict" and "Other meaning", see the
glossary of the user.

Status: APPROVED by the user on 2026-10-20.

## Technical nouns: TV, IPTV, and media

- **playlist** (tn): a list of channels or media items, for example an M3U file.
- **player** (tn): the part of an app that plays video and audio.
- **playback** (tn): the play of video or audio.
- **subtitle** (tn): text on the screen that shows the spoken words.
- **track** (tn): one audio or subtitle channel of a media item. Conflict: "track (v)" -> MONITOR (v).
- **codec** (tn): the method that changes video or audio into data, and changes the data back into video or audio.
- **resolution** (tn): the number of pixels of a video, for example 1920×1080.
- **bitrate** (tn): the quantity of data in 1 s of a stream.
- **segment** (tn): one short file of an HLS stream.
- **manifest** (tn): the playlist file of an HLS stream that lists its segments.
- **guide** (tn): the electronic program guide (EPG). Conflict: "guide (v)" -> PUT (v), MOVE (v).
- **program** (tn): one TV show in the guide. In this project, use `app` or `software` for a computer program. Conflict: "program (n)" -> SEQUENCE (n).
- **movie** (tn): a video that is not part of a series.
- **series** (tn): a TV show with episodes.
- **episode** (tn): one part of a series.
- **season** (tn): a set of episodes of a series.
- **genre** (tn): a category of movies or series, for example `Comedy` or `Drama`.
- **poster** (tn): the image of a movie or a series.
- **archive** (tn): the copies of programs from the last days that a provider keeps (catch-up).
- **catch-up** (tn): the function that plays a program from the archive.
- **favorite** (tn): a channel or an item that a user marks with a star.
- **remote** (tn): the remote control of a TV.
- **timezone** (tn): an area where all clocks show the same standard time.
- **clock** (tn): the time that a device shows.

## Technical verbs: media

- **stream** (tv): to send or receive media data continuously.
- **play** (tv): to show video or to make audio. forms: plays, played.
- **pause** (tv): to stop playback temporarily.
- **resume** (tv): to continue playback from the position where it stopped. Conflict: "resume (v)" -> CONTINUE (v).
- **seek** (tv): to move playback to a different time. forms: seeks, sought. Conflict: "seek (v)" -> GET (v).
- **rewind** (tv): to move playback back in time. forms: rewinds, rewound. Conflict: "rewind (v)" -> WIND (v).
- **mute** (tv): to stop the audio output.

## Technical nouns: IPTV Ultra screens and functions

- **current program** (tn): the program that a channel shows at this time.
- **next program** (tn): the program that starts after the current program.
- **details page** (tn): the page that shows the information about 1 movie or 1 series.
- **start page** (tn): the first page of IPTV Ultra, where you select a playlist.
- **star** (tn): the icon that marks a favorite.
- **country** (tn): the country where a movie was made, for example Canada.
- **age rating** (tn): a rating that shows if persons below a specified number of years can see a movie or a series, for example PG-13.
- **frame rate** (tn): the number of frames in 1 s of video.
